# RideFlow — Python dependencies
#
# Target interpreter: Python 3.13 (verified on 3.13.5, Windows, cp313 wheels)
#
# ─────────────────────────────────────────────────────────────────────────────
# VERIFIED — these are not guessed versions.
#
# Every pin below was resolved together in a single `pip install --dry-run`
# under Python 3.13.5 on 2026-08-06. The full set installs with no conflicts.
#
# This CLOSES blocking item A6 in PROJECT_PLAN.md Appendix A:
#   dbt-core 1.12.0 and dbt-duckdb 1.10.1 DO support Python 3.13.
#   The earlier concern that dbt lagged new Python releases does not apply
#   at these versions. No 3.11/3.12 fallback environment is required.
#
# One near-conflict was found and resolved: dbt-core constrains `pathspec`
# lower than black prefers. pip settles on pathspec 1.0.4, which satisfies
# both. Installing dbt and the dev tooling in SEPARATE environments would
# have hidden this; they are pinned together deliberately.
# ─────────────────────────────────────────────────────────────────────────────
#
# Install:
#   python -m venv .venv
#   source .venv/Scripts/activate      # Git Bash on Windows
#   pip install -r requirements.txt
#
# NOTE: create the venv locally. Do NOT use the system interpreter directly —
# it lives at "...\AI & ML\python.exe" and the ampersand is a shell
# metacharacter that breaks unquoted tooling on Windows.


# ─── Streaming transport ─────────────────────────────────────────────────────

# ─── Warehouse & transformation ──────────────────────────────────────────────

# ─── Event generation ────────────────────────────────────────────────────────
# NOTE: Faker==40.36.0 was pinned here and has been REMOVED after M2.
# The no-PII design (PROJECT_PLAN.md §6.5) means identities are opaque UUIDs,

# never actually imported. Verified with a grep before removal.
